# 🧭 一、需求分析（Functional Requirements）

------

## 🥇 1. 任务管理模块（Task Management）

### 📌 1.1 功能描述

用于管理“全局任务”，定义任务规则。

------

### 🧾 1.2 任务字段定义

```
Task {
  id
  name                    // 任务名称
  startDate              // 开始日期
  endDate                // 结束日期（可选）
  startReminderTime      // 每日开始提醒时间（如08:00）
  intervalMinutes        // 提醒间隔（分钟）
}
```

------

### 🔁 1.3 任务执行规则（核心🔥）

支持三种规则（可组合或单选）：

#### 🟢 周几规则（Weekday Rule）

- 周一 / 周三 / 周五

------

#### 🟡 单双日规则（OddEven Rule）

- 日期奇数 / 偶数

------

#### 🔵 间隔天数规则（Interval Rule）

- 每 N 天执行一次

------

### 🧩 1.4 功能操作

- 新增任务
- 编辑任务
- 删除任务
- 查看任务列表

------

### 🎯 目标

> 定义“任务如何被生成每日任务”

------

## 🥈 2. 每日任务模块（Daily Task）

------

### 📌 2.1 功能描述

展示“当天实际需要执行的任务”。

------

### 🔄 2.2 生成机制（核心🔥）

每天固定时间（默认 08:00）：

```
Task（规则）
   ↓
Scheduler筛选
   ↓
生成 DailyTask
```

------

### 📊 2.3 数据结构

```
DailyTask {
  id
  taskId
  date
  status
}
```

------

### 🧠 2.4 状态定义

```
0 = 未完成
1 = 已完成
2 = 偷懒
```

------

### 🎨 2.5 UI展示

#### ✔ 已完成区

- 已完成

------

#### ❌ 未完成区

- 未完成
- 偷懒

👉 UI需分组展示（增强可读性）

------

### ⏰ 2.6 提醒机制（核心🔥）

```
startReminderTime 到达后开始提醒
每 intervalMinutes 触发一次通知
直到：
    - 状态=已完成
    - 或当天结束
```

------

### 🔔 2.7 通知行为

- 本地通知 + 震动
- 已完成任务停止通知

------

### 🎯 目标

> 管理“当天执行状态 + 提醒执行”

------

# 🧱 二. 数据表设计（与代码完全一致）

------

## 🥇 2.1 task 表（任务规则表）

> 用于定义任务的长期规则，不记录每日状态

```
CREATE TABLE task (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT NOT NULL,

  start_date TEXT,
  end_date TEXT,

  start_reminder_time TEXT,
  interval_minutes INTEGER,

  rule_type INTEGER,
  rule_config TEXT
);
```

### 📌 字段说明

| 字段                | 说明         |
| ------------------- | ------------ |
| id                  | 主键         |
| name                | 任务名称     |
| start_date          | 开始日期     |
| end_date            | 结束日期     |
| start_reminder_time | 提醒时间     |
| interval_minutes    | 间隔规则     |
| rule_type           | 规则类型     |
| rule_config         | JSON扩展配置 |

------

## 🥈 2.2 daily_task 表（每日任务执行表）

> 用于记录每天实际执行情况（核心业务表）

```
CREATE TABLE daily_task (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  task_id INTEGER,
  task_name TEXT,
  date TEXT,
  status INTEGER
);
```

### 📌 字段说明

| 字段      | 说明                        |
| --------- | --------------------------- |
| id        | 主键                        |
| task_id   | 关联 task 表                |
| task_name | 任务快照（防止历史变更）    |
| date      | 执行日期                    |
| status    | 状态（0未完成 1完成 2偷懒） |

------

## 🥉 2.3 user 表（用户表）

> 用于登录与账号体系

```
CREATE TABLE user (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  username TEXT,
  password_hash TEXT
);
```

### 📌 字段说明

| 字段          | 说明     |
| ------------- | -------- |
| id            | 主键     |
| username      | 用户名   |
| password_hash | 密码哈希 |

------

## 🏅 2.4 daily_stats 表（统计表）

> 用于缓存每日统计结果（避免重复计算）

```
CREATE TABLE daily_stats (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  date TEXT UNIQUE,
  total INTEGER,
  finished INTEGER,
  skipped INTEGER,
  completion_rate REAL
);
```

### 📌 字段说明

| 字段            | 说明          |
| --------------- | ------------- |
| id              | 主键          |
| date            | 日期（唯一）  |
| total           | 总任务数      |
| finished        | 完成数        |
| skipped         | 偷懒数        |
| completion_rate | 完成率（0~1） |
