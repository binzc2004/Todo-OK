# SelfDiscipline - 强监督型 ToDo 应用

## 项目简介

SelfDiscipline 是一款以“强监督”和“高自定义规则”为核心的待办事项管理应用。
 相比传统 ToDo 应用仅提供轻量提醒，本项目通过周期性通知、任务级调度和数据反馈机制，强化用户执行力，提升任务完成率。

项目目标是构建一个能够持续干预用户行为的任务系统，从而帮助用户建立稳定的自律习惯。

------

## 项目目标

- 提供可配置的任务规则与提醒机制
- 通过高频调度与通知增强执行约束
- 基于完成率进行行为反馈
- 支持数据导入导出，保证可迁移性

------

## 功能说明

### 1. 任务管理

- 支持任务的增删改查
- 支持自定义任务规则
- 支持设置开始提醒时间
- 支持设置提醒周期（如按小时、按天等）
- 支持任务详细描述
- 每个任务具备独立调度能力

------

### 2. 提醒系统

- 支持通知提醒
- 支持震动提醒
- 支持声音提醒
- 支持周期性重复提醒
- 每个任务独立控制提醒策略

------

### 3. 每日任务机制

- 每天 8:00 自动生成当日任务
- 每天 24:00 自动统计当日完成情况
- 自动计算每日完成率

------

### 4. 数据统计

- 支持按时间范围查看完成率
- 支持按日期查看任务完成情况
- 支持查看某一天的任务详情
- 提供周期性数据统计能力

------

### 5. 用户与数据管理

- 提供用户页面
- 支持数据导出（备份）
- 支持数据导入（迁移）

------

### 6. 行为反馈机制

系统根据用户完成情况提供反馈：

- 完成率较高时提供正向反馈
- 完成率较低或连续未完成时提供负向反馈

该机制用于增强用户对任务执行的感知与约束

------

## 项目亮点

- 基于规则引擎的任务生成机制
- 每个任务独立调度，提高灵活性
- 固定时间节点驱动（每日生成 + 每日总结）
- 多通道提醒系统（通知 / 声音 / 震动）
- 完成率驱动的行为反馈闭环
- 强监督设计导向

## 核心模块说明

- `rule_engine.dart`
   负责解析任务规则并决定任务生成逻辑
- `task_generator.dart`
   根据规则生成每日任务
- `reminder_engine.dart`
   控制任务提醒的触发时机与周期
- `daily_summarizer.dart`
   负责每日任务完成情况统计
- `work_manager.dart`
   后台任务调度入口
